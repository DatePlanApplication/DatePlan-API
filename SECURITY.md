# Política de Segurança

## Reportando uma vulnerabilidade
**Não abra uma issue pública.** Envie os detalhes por e-mail para **mayckgomes.dev@gmail.com**
(ou use "Report a vulnerability" na aba Security do GitHub, se disponível), incluindo:

- descrição e impacto;
- passos para reproduzir;
- versão ou commit afetado.

Responderemos assim que possível e daremos crédito a quem reportar, se desejar.

## Escopo
Este repositório contém o backend (API REST). O aplicativo é mantido em outro repositório da organização.

Se você encontrar um segredo exposto (token, chave, credencial) no código ou no histórico, avise por e-mail em vez de
abrir uma issue.
